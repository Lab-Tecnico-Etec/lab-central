## Preservação e autoria

Os repositórios antigos de Sorveteria e Java permanecem preservados, mas não são apresentados como projetos atuais em destaque. Nenhum repositório ou histórico deve ser apagado apenas por estar fora do escopo.

Só publique trabalhos e informações com autorização dos envolvidos e conforme as regras da escola. Registre contribuições reais, não inclua credenciais ou dados pessoais desnecessários e mantenha a documentação atualizada.
