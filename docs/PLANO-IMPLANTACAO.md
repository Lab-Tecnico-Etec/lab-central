# Plano simples para os TCCs da ETEC

## Objetivo

Usar a organização Lab-Tecnico-Etec para preservar e organizar Trabalhos de Conclusão de Curso, sem criar processos desnecessários.

## Estrutura mínima

- **Repositório institucional privado:** ponto de entrada e orientação para os TCCs.
- **Um repositório por TCC:** recomendado quando o projeto precisar de código, documentação e histórico próprios.
- **Central:** lista de TCCs cadastrados e orientações curtas.

## Checklist para cada TCC

- [ ] Confirmar integrantes e autorização para armazenar/compartilhar o material.
- [ ] Criar um README com título, resumo, tecnologias e instruções.
- [ ] Organizar código, documentação e arquivos necessários.
- [ ] Verificar se não há senhas, tokens, dados pessoais ou informações restritas.
- [ ] Definir a visibilidade de acordo com as orientações da ETEC e dos integrantes.
- [ ] Confirmar que o repositório pode ser acessado por quem precisa.

## Repositórios anteriores

Sorveteria e Projetos-Java permanecem na organização, sem exclusão ou alteração de seus arquivos, mas estão fora do escopo de TCCs. Os repositórios originais também devem permanecer intactos.

## Limites

Este plano não altera automaticamente permissões, visibilidade, proteção de branches ou membros. Essas configurações devem ser verificadas no GitHub por alguém com autorização administrativa. O GitHub não substitui cópias de segurança nem as regras oficiais da escola.
